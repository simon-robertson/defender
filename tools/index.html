 WORKSHOP GUIDE

Build in units. Place in boxes.

Model studio

Select a rigid part, material and Y slice. Paint the 24 × 24 grid to add or recolour cells; erase removes cells only from the selected part. Choose a face to override just that surface. Other parts appear muted.

Use the three variant tabs for base and upgrades. Copy a variant to start the next version. Add parts, set their parents and pivots, and use pose sliders to check movement. Poses are temporary previews; saved meshes remain in their grid-aligned bind pose.

Clean surfaces

Each cell has one owner. Internal faces are removed within each part; adjacent exposed faces merge only when their materials match. Interfaces between moving parts stay intact. Check the full range of motion for intersections—pose sliders do not perform collision detection.

Level studio

Choose a saved model, variant and quarter-turn, then paint boxes on the plan. Each box is 24 units. Models follow the ground height; Extra Y boxes add 24-unit offsets. Path mode appends flat, dry edge-connected boxes in order; the Undo step button removes the last path box. This route is authoring metadata, not a final pathfinding rule.

Shift-drag the plan to pan; scroll to zoom. Select an occupied box to inspect it. Erase removes a model; path removal uses Undo path step or Clear path. Models must be saved before levels can reference them.

Terrain

Choose Terrain in the level plan. Paint whole 24 × 24 boxes with Raise +1, Lower −1, Set ground, Set water, or Drain. Heights change in 1-unit steps. Water depth is above ground: ground 4 and depth 8 puts the surface at Y=12. Paths are protected from terrain brushes. The Flat path height field moves the entire route together.

Ground-anchored models follow dry mounds. Edits that flood their supports or bury absolute placements are rejected. Undo includes terrain. Water is authored per box and does not flow automatically.

Saving and materials

Save writes JSON into the project's assets folder. Export downloads source or compiled mesh JSON. Unsaved drafts recover from this browser's local storage. Undo history is bounded to 40 edits or 16 MiB per document.

Emission and reflectiveness range from 0 to 1. The material view lets you inspect either value. The colour preview uses simple editor shading; it does not simulate reflections. No game effects are implemented.

Keyboard: Ctrl/⌘ S save, Ctrl/⌘ Z undo, Ctrl/⌘ Shift Z redo. No packages, external fonts or network services.
