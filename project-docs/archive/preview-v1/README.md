# Original rectangular previews

These four level snapshots and the original scenery/layout generator sources preserve the 14 × 10 appearance studies before the user-requested square production rebuild on 17 October 2026. Generator files are kept as text references, not runnable imports. Current sources live under `assets/` and `scripts/production-*.js`.

The approved turret and dog designs are retained by the rebuild. This archive does not change gameplay or restore the previous scenery into the active model library.
