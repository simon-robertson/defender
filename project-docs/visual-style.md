## Established visual constraints

- Latest title/menu direction (18 October): remove all defences and enemies, leaving the scenery-only background with the existing title/menu composition. This supersedes depicting units in the title artwork. The preceding model-fidelity request produced v2; [v3](concepts/title-menu-moss-porcelain-v3.md) is the current proposal. No changes to game models or menu implementation are authorised by this art iteration.
- Show forms that could be authored from axis-aligned quads. Cubes are one building block; every model does not need to be a single cube or a stack of identical cubes.
- Keep scale consistent: a grid cell is 1 unit along each axis, and a placement box is 24 × 24 × 24 units (XYZ). Model width and length must each fit within 24 units; height may exceed 24 units.
- Use colour and geometry to express surfaces without relying on painted texture detail. The four zone palettes below define primary colours as guidelines, not a restriction to those exact swatches. Tints, shades, and related colour variations are approved for shading and surface variety while retaining each zone's visual identity.
- Retain the same player arsenal across zones and recolour it to match each palette. Each zone has its own enemy types, whose visual identities remain to be designed.
- Design three variants for every arsenal item: base model, upgraded model 1, and upgraded model 2. Each variant follows the same footprint limit and receives the zone colour changes. The visual differences between upgrade variants remain to be designed.
- Make moving parts understandable as separate components, with plausible pivots for turret aiming or articulated limbs.
- Keep units, towers, routes, and buildable terrain legible at the intended play scale. Their exact designs and rules remain open.
- Consider how a section of a larger level reads when the camera can pan beyond the current view.
- Do not introduce fog, haze, or unapproved effects into a concept as if they are part of the agreed look. Any proposed effect must be explicitly identified for discussion.

With all four colour directions selected as zones, use close studies of the shared arsenal, each zone's enemies, and terrain to refine them. Compare each arsenal item's base model and two upgraded models at a common scale, then compare zone colour variants using the same models and framing. These studies can propose asset designs without treating every pictured detail as approved game content.

Show close views only alongside a play-scale view so fine detail does not drive choices that disappear during play. Label choices introduced by an image as proposals, and record the user's selection before carrying them into implementation. Generated imagery is a visual reference, not evidence that an effect is performant or that geometry is ready for the engine.
