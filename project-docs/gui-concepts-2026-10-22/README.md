# DEFENDER GUI concepts

Two visual directions for review, created with the built-in imagegen tool using existing game artwork as the world reference. These are concept images; the player GUI has not been implemented or replaced.

- **Command panel flow** — charcoal panels, ivory type and amber actions. The three frames show equipment selection, deployment and combat. Each step exposes its own decisions; the equipment tray disappears during combat.
- **Enamel command tray** — warm ivory plates and forest-green type, with a small contextual weapon readout and a single bottom command tray. A lighter option that follows the porcelain models.

Both directions preserve battlefield visibility, distinguish valid placement from the primary action, and retain the small performance footer. Labels, counts and model depictions are illustrative; implementation must use the actual campaign configuration and unlocks. In particular, the dark flow sheet's prices and breach pips are visual placeholders, not balance proposals.

Full generation prompts are saved in `prompts.txt`. No production UI change, player reload or publication is included.
